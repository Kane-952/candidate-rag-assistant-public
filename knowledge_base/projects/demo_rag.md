# DEMO 候选人资料问答项目

以下项目经历是专门编写的虚构样例，供开发和评测使用，不代表作者真实经历。

## 项目与检索方法

DEMO 候选人设计了一个读取 Markdown 的候选人资料问答演示。使用 BM25 做关键词检索，本地 Embedding 做向量检索，用 RRF 融合两路排序，再用可选的 Cross-Encoder 重排。

## 为什么采用混合检索

虚构项目选择混合检索，是因为技术缩写和专有词适合关键词匹配，而改写问题需要语义检索。RRF 用排序位置融合两路结果，避免直接比较不同尺度的分数。这是样例中的设计理由，没有记录正式效果对比。

## 回答与证据边界

演示包含独立证据门控、引用 ID 校验与生成后事实核验。资料不足时拒答，不用常识补充经历；所有展示正文需要完成核验。没有提供准确率、召回率、性能提升百分比或生产用户数。
