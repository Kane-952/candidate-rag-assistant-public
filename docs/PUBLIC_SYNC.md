# 展示仓库的手动更新

展示版只含虚构资料、空凭据与通用资源。更新时在本地私有工作目录导出选定源 commit 的跟踪文件，不复制 `.git`、`.env`、数据库、索引、收件箱、日志、缓存或导出结果。

逐项替换知识库、前端身份与 SEO、头像、LLM 提示、邮件模板、关联测试、文档和评测数据。不能仅改姓名后保留原教育/雇主/项目组合。样例邮箱使用 `example.com`，未知信息选择不记录或明确拒答。

对候选树与拟提交内容做敏感信息扫描及人工复核，包括联系方式、账号、身份词、路径、域名、凭据、截图和文件元数据。确认差异只含允许公开的内容，运行回归测试；如果源版本改变，核对本展示版修复是否仍成立。

发布时只在本仓库提交脱敏后的文件，使用账号公开称呼及 GitHub noreply 作者邮箱。不要 mirror、导入 tag、merge 原仓库历史、发布私有审查报告或上传运行数据。记录本次来源 commit 与修改范围，后续更新重复这套流程。

如果发现真实凭据进入任何可访问历史，先停下并单独处理轮换；删除当前文件不能撤销凭据。本文不提供自动定时同步。
