# 延迟观察与请求上限

本展示版未做真实模型性能基准，没有迁入原个人项目的历史数字。启动阶段预热 Embedding 和可选重排模型，失败则健康检查返回 unavailable。

MAX_PENDING_CHATS（默认 4）是执行中与等待中的请求总上限，不是吞吐保证；满额返回 429。全局锁串行执行本地推理，单 worker 运行。事件队列有界。

流式连接断开后取消等待和后续阶段。已经发出的模型请求可能等到响应/HTTP 超时；同步的本地推理也不能被立即抢占。取消后不把结果作为成功问答持久化。

python scripts/benchmark_latency.py 使用配置的服务地址与本地鉴权，会消耗真实模型 API 用量。first_visible_ms 代表核验通过后首次正文到达，不能称为模型原始 TTFT。管理员 Trace 可以分别查看模型生成和验证阶段。没有并发容量或生产 SLA 声明。
